# 卒中卫士初赛外网监控设计

## 目标

在现有 `ESP32-S3 -> MQTT -> FastAPI -> InfluxDB -> 豆包 -> S3` 链路上增加一个可从外网访问的初赛演示网页。网页使用单个演示账号登录，用户输入设备 ID 后连接设备，每 5 秒只读同步监控数据和大模型建议。

## 明确不做

- 不做 SQLite、用户注册、多租户、设备归属或六位绑定码。
- 不做 WebSocket；初赛统一使用 5 秒轮询。
- 不做 PC 客户端远程模式。
- 不从网页修改用户档案、Wi-Fi、MQTT 凭据、融合权重、危险阈值或否决规则。
- 不上传或展示原始图像、音频、MFCC、关键点或 ROI。
- 不使用模拟分数补齐缺失模态。

## 登录

- VPS `.env` 提供 `SG_DEMO_USER`、`SG_DEMO_PASSWORD` 和 `SG_DEMO_SESSION_SECRET`。
- FastAPI 启动时将密码转换为进程内 scrypt 哈希并从环境变量删除明文。
- 登录成功后签发带过期时间和 HMAC-SHA256 签名的 `HttpOnly`、`SameSite=Strict` Cookie。
- Cookie 默认要求 HTTPS；开发联调只有显式设置 `SG_ALLOW_INSECURE_HTTP=1` 才允许 HTTP。
- 登录失败统一显示“账号或密码错误”，不记录密码或 Cookie。

## 设备连接

1. 用户登录后输入设备 ID，例如 `sg-0001`。
2. 后端校验设备 ID 只包含字母、数字、下划线和短横线，长度不超过 32。
3. 后端检查 MQTT bridge 是否收到该设备的合法 uplink。
4. 最近 30 秒内收到合法 uplink 时连接成功；否则显示“设备离线或尚未上报”。
5. 连接的设备 ID 写入签名会话 Cookie，不写数据库。
6. 用户可以断开并输入其他设备 ID。

本功能只是在网页会话中选择要查看的 MQTT 设备，不向 S3 下发控制命令。

## 同步内容

网页每 5 秒调用一次只读 API，返回：

- 设备 ID、在线状态、最后接收时间。
- `face`、`speech`、`tongue`、`eye`、`csi` 和 `final`。
- 镜端确定的 `level`、`reasons` 和 `veto_by`。
- 最新大模型建议文本、建议来源和建议时间。

F/S/T/E 为 `null` 时显示“未接入”。CSI 必须显示 S3 实际上报值；不得使用界面默认值 80。大模型建议不能修改或覆盖镜端风险等级。

## API

- `POST /demo/api/login`
- `POST /demo/api/logout`
- `GET /demo/api/session`
- `POST /demo/api/connect`
- `POST /demo/api/disconnect`
- `GET /demo/api/device`
- `GET /demo`：登录或监控页面入口

除登录页和现有 `/health` 外，所有 `/demo/api/*` 均校验签名会话。

## 页面

- 登录视图：项目名称、账号、密码、登录按钮和医学免责说明。
- 未连接视图：设备 ID 输入框、连接按钮、服务器健康状态。
- 监控视图：设备在线状态、五模态评分、融合等级、触发原因、大模型建议、最后同步时间、刷新和断开按钮。
- 危险状态固定突出“立即拨打 120”；产品始终标注为风险提示而非诊断。
- 页面适配 390x844、1024x768 和 1440x900，不出现文字或控件重叠。

## 数据与故障

- MQTT bridge 在合法 uplink 通过 topic/device/schema 校验后记录服务器接收时间。
- 设备时间戳只用于展示，在线判定使用 VPS 接收时间，避免 S3 时钟误差。
- MQTT 或设备中断时保留最后一条结果并显示离线，不生成新分数。
- LLM 不可用时继续显示镜端等级和固定安全建议。
- 网页关闭或 VPS 不可用不影响 S3 本地融合、声光告警和 MQTT 重连。

## 验收

1. 错误账号密码不能登录；明文凭据不进入日志和 Git。
2. 未登录访问设备 API 返回 401。
3. 输入 `sg-0001` 后，只有最近 30 秒有合法 MQTT uplink 才连接成功。
4. S3 不插 PC 时，网页每 5 秒显示真实 CSI、融合等级和豆包建议。
5. 缺失 F/S/T/E 显示“未接入”，不出现模拟 80。
6. 设备停止上报超过 30 秒后页面显示离线。
7. API 和网页中没有原始音视频或可重建生物特征。
8. 完整本地测试、VPS 部署、浏览器桌面/移动截图和真机断开 USB 验收均通过。
