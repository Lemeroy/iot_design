# GC2145 YUV ESP-WHO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the corrupted GC2145 RGB565 capture path with YUV422 capture and local RGB888 conversion for ESP-WHO.

**Architecture:** Keep camera ownership and all external protocols unchanged. `camera_capture_adapter.cpp` owns one reusable PSRAM RGB888 buffer and converts each YUV422 frame before inference; USB preview encodes the original frame only when requested.

**Tech Stack:** ESP-IDF 5.5.3, esp32-camera 2.1.7, ESP-DL/ESP-WHO, pytest static firmware tests.

## Global Constraints

- Raw audio and video stay local and never enter MQTT, VPS, or LLM payloads.
- I2C address `0x52`, register `0x01`, and four-byte bbox response remain unchanged.
- Face bbox is not a medical F score.
